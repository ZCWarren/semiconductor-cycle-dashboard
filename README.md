# 半导体周期／景气罗盘

一个用于理解半导体周期的中文交互式研究页面，包含周期演示、五类赛道定位、全球与中国大陆行情对比、招聘薪酬信号，以及新闻、书籍和研报来源。

## 本地运行

```bash
npm install
npm run dev
```

## 自动更新与部署

GitHub Actions 工作流位于 `.github/workflows/update-and-deploy.yml`：

- 每月 5 日 11:17（Asia/Shanghai）运行，GitHub 定时任务可能延迟。
- 通过 Yahoo Finance 图表接口获取月度价格，生成最近 12 个月的归一化快照。
- 全部标的成功下载并通过日期、数量校验后才写入 `src/market.json`。
- 提交变化、构建站点并部署到 GitHub Pages。
- 也可在 Actions 页面手动运行 **Update market data and deploy**。

新闻、产业判断、研报、招聘与薪酬是带日期的研究快照，不自动刷新。行情月度更新不代表周期判断会随之自动改变。

## 数据口径

- 全球：费城半导体指数及英伟达、台积电 ADR、阿斯麦 ADR、美光科技。
- 中国大陆：中芯国际、北方华创、韦尔股份、海光信息四股等权观察篮子，不是可投资指数。
- 使用复权月度价格计算归一化表现；最新一个月通常是未完整月份。
- 本项目仅供教学与研究，不构成投资建议。
